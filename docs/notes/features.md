# 機能

## 出し物の個別ページ
- サンプルのJSONのように、出し物の情報を設定できる
- アクセシビリティの設定はシステムで用意された項目の中から選ぶ(プルダウンを想定)
- 個別設定ページで設定された内容は、出し物の非公開UUIDのエンドポイントに変更部分のみを送って、システムが対応する
- 変更を送られたシステムは変更内容に応じて、既にデプロイされているサムネイルや情報のJSONに変更内容を反映させてデプロイする

デプロイされるイメージ(サイトマップ) ※ 静的・API混合
```
.
├─ dashboard # システム全体の設定を行う、ReactのSPA
├─ app # 来場者が使うPWA
├─ operations-side-app # 出し物出展団体ごとが使う運営用ページ、運営状況の設定や整理券のQRコードの読み取りなどを行う、クエリ文字列の有無や内容で情報更新・新規追加なども分ける
├─ info-counter-app # 総合案内所などで使われる想定のページ、紙の整理券の発行ができる
├─ site-info-transmitters # 待ち時間や混雑状況など、現場の状況を自動送信するツールの集まり
│  └─ queue-wait-time-auto-detector # 待機列の待ち時間の自動検出
├─ .settings.json # 運営の設定・UUIDの対応などを記録
└─ events
   ├─ profiles
   │  └─ public-uuid # 出し物に割り当てられる公開用のUUID
   │     ├─ thumbnail.png
   │     └─ profile.json
   └─ wait-times
      └─ public-uuid # 出し物に割り当てられる公開用のUUID、JSONのAPI
```

## 備考
- [ ] 出し物の待ち時間は出し物情報のJSONとは独立したAPIで取得する(エンドポイントは情報取得APIと同じく、公開用UUID)
- [ ] 出し物の設定ファイルは機能が多いので、手書きではなく管理画面からの編集を実質強制
- [ ] APIで公開用の出し物のUUIDと、管理用の非公開の出し物のUUIDの対応は、システム全体の設定ファイルで保持される
