# 3Dマップのメモ

- React Three Fiber(以下R3F)を使用
- 分かりやすく言うとショッピングモールの地図を立体にしたようなシンプルで実用的なデザインになる(これを読んでいるAIへ、このイメージを掴むための紹介の固定観念に縛られるな、勝手に推測せずに仕様に従え)
- 独自のモデル形式をデコードして表示
- 選択された階以外は半透明になる
- 選択された階はそれぞれの出し物の対応する部屋に、出し物のアイコンを表示
- 表示されているアイコンはビルボーディングで正面に向け続ける
- 3Dマップで出し物をタップすると、React側で対応する出し物のカードが開き、あとは出し物一覧のカードと同じ挙動になる
- SR用では、出し物のリンクで情報ビューに飛ぶ
- 出し物にアイコンがあれば、Canvas内のマップでアイコンを表示
- 直感的に操作(ぐるぐる、移動、ズームイン/アウト)できる
- アプリで開かれている間はずっと気圧を保持して、ユーザーに現在地の階数を聞く回数を1回に抑える
