# 3Dマップのデータの内容のメモ

- 頂点(内部の識別IDを持つ)と直線(点と点を結ぶ)と曲線(点と点を結ぶ)を持つ
- 曲線はポリゴンではなくベジェ曲線で保持
- 多面体(主に直方体)の内側が部屋(出し物)になる仕様
- 階段やエレベーターは複数回に跨る部屋という扱いで実現
- 敷地 → 建物 → 階(場合による) → 部屋 という親子関係(システムの都合で、外は階を持たない一種の建物という扱い)
- 部屋ごとに追加の情報を持たせられる
  - 対応する出し物の公開用ID(システムの都合で出し物に限らず、トイレや階段も全て出し物として扱われる)
  - 位置情報
- 出し物は親子関係で包まれているので、個々の出し物は階数などの情報を持たない
