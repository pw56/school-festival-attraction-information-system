# round

## 概要
プレイ終了時に、そのラウンドでプレイしていた組の全プレイヤーの得点を送信・記録するためのAPI。

---

## 基本情報
| 項目 | 内容 |
|---|---|
| 通信方式 | REST API |
| データ形式 | JSON(`application/json`) |
| HTTPメソッド | POST |
| エンドポイント | `/api/round` |

---

## リクエスト仕様

### ボディ
任意のプレイヤーIDをキー、得点を値とするオブジェクト。

### パラメータ
| キー | 型 | 内容 |
|---|---|---|
| `{player_id}` | `number` | 動的キーを使用。キーはプレイヤーを識別する固有のIDまたは名前。値にはそのターンに獲得した得点(整数)を指定。 |

### サンプル
```json
{
  "player1": 20,
  "player2": 50
}
```

---

## レスポンス仕様

### 成功時

#### ボディ
データの受信および保存処理が正常に完了したJSONオブジェクト。

#### ステータスコード
以下のステータスコードで応答。

```
200
```

#### パラメータ
| キー | 型 | 内容 |
|---|---|---|
| `message` | `string` | メッセージ。 |

#### サンプル
```json
{
  "message": "Scores updated successfully."
}
```

### 失敗時

#### ボディ
処理に失敗したときのレスポンスボディ。

#### ステータスコード
以下のステータスコードで応答。

```
400
```

#### パラメータ
| キー | 型 | 内容 |
|---|---|---|
| `message` | `string` | エラーメッセージ。 |

#### サンプル
```json
{
  "message": "An error occurred while processing scores."
}
```
