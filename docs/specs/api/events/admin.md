# 管理者向けAPI群

## 概要
出し物登録・設定編集用API。

---

## 基本情報
- 通信方式: REST API
- データ形式: JSON(`application/json`)

---

## 1) 出し物新規作成(追加)
- メソッド: POST

リクエストボディ: `id`だけがないスキーマ通りのオブジェクト。

成功時: `201 Created` と作成したリソース情報を返す。

---

## 2) 出し物更新
- メソッド: PUT

リクエストボディ: 更新した差分のオブジェクト。

成功時: `200` と更新済みオブジェクト。

---

## 3) 出し物削除
- メソッド: DELETE

成功時: `200` または `204`。
